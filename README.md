# Dnd_icons — иконки безделушек D&D (таблица d100)

Коллекция иконок **256×256 PNG** к таблице безделушек d100 (D&D 5e, Player's
Handbook) в едином стиле **«ручная живопись»**: художник-иллюстратор, цифровое
масло, один тёплый ключевой свет, матовые краски, упрощённые читаемые формы.

## Что где лежит

```
icons/painted/            готовые иконки 256×256 (единый фон #28323A)
icons/painted/transparent/ те же иконки с альфа-каналом
masters/painted/          исходники 1024×1024, из которых собираются иконки
preview/                  контактные листы: вся коллекция, детали ×2, проверка масштаба
index.html                статичная галерея (открывается локально, картинки относительными путями)
manifest.json             перечень иконок: id, номер по d100, названия ru/en
scripts/build_icons.py    пайплайн сборки
```

## Как пересобрать

```bash
pip install pillow numpy scipy
python3 scripts/build_icons.py
```

Что делает скрипт:

1. читает мастер-файлы из `masters/painted/`;
2. вырезает предмет из плоского фона (порог по цвету + самая крупная связная
   область, поэтому мягкая тень под предметом не попадает в маску);
3. масштабирует предмет до 202 px по длинной стороне и центрирует на холсте
   256×256 (предмет занимает ~79% кадра);
4. сохраняет обычную и прозрачную версии, пересобирает превью, галерею и манифест.

## Как добавить предмет

1. Положить мастер 1024×1024 в `masters/painted/<id>-<slug>.png`.
   Фон — плоский однотонный (та же схема: тёмный сине-серый), предмет по центру,
   занимает ~70% кадра, без обрезки по краям.
2. Дописать запись в `ITEMS` внутри `scripts/build_icons.py`.
3. Запустить скрипт — иконка, прозрачная версия, превью и галерея обновятся сами.

## Заметки по стилю

* Стиль-эталон — «Мумифицированная рука гоблина» (01) и «Механический канарейка
  в гномьем фонаре» (44): дисциплина формы и свет как у первой, более свободный и
  тёплый мазок как у второй. Новые предметы рисуем в этом «среднем» ключе.
* Стараемся избегать фотореализма и 3D-рендера: матовые краски, видимые мазки,
  кромки предмета встречаются с фоном без мягкого ореола.
* Фон коллекции — единый `#28323A`, чтобы иконки в одном инвентаре выглядели
  однотипно; силуэт читается и в 64, и в 32 px (см. `preview/painted-sizes.png`).
