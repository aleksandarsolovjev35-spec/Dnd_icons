# Dnd_icons — иконки предметов D&D (безделушки, таблица d100)

Иконки **256×256 PNG** для безделушек из таблицы d100 (D&D 5e, Player's Handbook).
Все изображения сгенерированы вручную (нейросетью) и собраны скриптом: предмет
вырезается из фона, кадрируется и центрируется на квадратном холсте.

Как добавить ещё: положить мастер-файл 1024×1024 в `masters/painted/<id>-<slug>.png`,
дописать предмет в `PAINTED_ITEMS` внутри `scripts/build_icons.py` и запустить скрипт —
иконка, прозрачная версия, превью и галерея обновятся сами.

### 2. Один предмет в 10 стилях — для выбора стилистики проекта

```
icons/styles/painted.png        ручная живопись (AAA RPG)
icons/styles/pixel16.png        16-битный пиксель (SNES)
icons/styles/vector.png         плоский вектор (UI, roguelike)
icons/styles/realism.png        фотореализм 3D
icons/styles/comic.png          комикс, плотная тушь
icons/styles/watercolor.png     акварель на пергаменте
icons/styles/engraving.png      гравюра (ч/б, ксилография)
icons/styles/isometric.png      low-poly 3D
icons/styles/stained-glass.png  витраж
icons/styles/neon.png           неон / киберпанк
```

Дополнительно:

* `icons/painted/transparent/`, `icons/styles/transparent/` — те же иконки с
  прозрачным фоном (кроме «гравюры» и «витража»: там фон — часть стиля);
* `icons/mosaic/stained-glass-*.png` — витраж четырьмя плитками 128×128
  (при сильном уменьшении мелкие детали витража теряются);
* `preview/` — контактные листы для быстрого просмотра и сравнения;
* `index.html` — статичная галерея со всеми иконками (открывается локально);
* `masters/` — исходники 1024×1024, из которых собираются иконки;
* `manifest.json` — перечень иконок с названиями (ru/en) и номером по d100.

## Как пересобрать

```bash
pip install pillow numpy scipy      # зависимости скрипта
python3 scripts/build_icons.py      # иконки + превью + index.html
```

Скрипт `scripts/build_icons.py`:

1. читает мастер-файлы из `masters/`;
2. вырезает предмет из плоского фона (порог по цвету + самый крупный связный
   компонент, поэтому мягкая тень под предметом не попадает в маску);
3. масштабирует предмет до ~200 px по длинной стороне и центрирует на холсте
   256×256; для пиксель-арта размер выставляется целым числом пиксельных блоков,
   чтобы сетка не «поплыла»;
4. сохраняет обычную и прозрачную версии, собирает превью и галерею.

## Заметки по стилю

* Фон «ручной живописи» — единый тёмно-синий `#28323A` для всей коллекции,
  чтобы иконки в одном инвентаре выглядели однотипно.
* Предмет занимает ~79% кадра: при 64 и 32 px силуэт ещё читается
  (см. `preview/painted-sizes.png`).
* Стили «pixel16» и «stained-glass» лучше всего выглядят в 256×256 — это их
  родное разрешение.
