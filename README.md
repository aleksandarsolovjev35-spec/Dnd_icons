# Dnd_icons — иконки безделушек D&D (таблица d100)

11 безделушек из таблицы d100 (D&D 5e, Player's Handbook) в едином стиле
**«ручная живопись»**. Иконки **256×256 PNG**.

## Стиль

Ориентир — две иконки-эталона: **рука гоблина** (d100 01) и **канарейка в фонаре**
(d100 44). Всё остальное нарисовано «посередине» между ними:

* масляная живопись, матовые краски, заметные мазки;
* умеренно упрощённые формы, аккуратный читаемый силуэт;
* один тёплый источник света + холодная тень, мягкие блики;
* без фотореализма, без 3D-рендера, без свечения-ореола вокруг предмета.

Фон у всех иконок один — `#28323A`, чтобы в инвентаре предметы смотрелись вместе.

## Как добавить предмет

1. Положить исходник 1024×1024 в `masters/painted/<id>-<slug>.png`
   (генерация: фон — плоский `RGB 40,50,58`, предмет по центру ~70 % кадра).
2. Дописать предмет в список `ITEMS` в `scripts/build_icons.py`.
3. Запустить сборку — иконка, прозрачная версия, превью и галерея обновятся сами.

```bash
pip install pillow numpy scipy     # зависимости
python3 scripts/build_icons.py
```

Что делает скрипт: определяет цвет плоского фона по рамке изображения, вырезает
предмет по порогу цвета (берётся только самый крупный связный компонент, поэтому
мягкая тень под предметом в маску не попадает), масштабирует предмет до ~200 px
по длинной стороне, центрирует на холсте 256×256, сглаживает край маски и
сохраняет обе версии. Для отдельных предметов порог и сглаживание можно
переопределить (`thr`, `feather`) прямо в списке `ITEMS`.
