# Dnd_icons — иконки безделушек D&D (таблица d100)

11 безделушек из таблицы d100 в едином, закреплённом стиле **«ручная живопись»**.
Иконки **256×256 PNG**.

## Стиль (закреплён)

Эталон — **01 Мумифицированная рука гоблина**, к ней подтянуты все остальные иконки
(44 канарейка — второй референс). Правила:

* масляная живопись, матовые краски, заметные мазки, плотный цвет;
* умеренно упрощённые формы, аккуратный читаемый силуэт;
* один тёплый контровой свет по краю предмета + холодная тень, мягкие блики;
* без фотореализма, без 3D-рендера, без свечения-ореола вокруг предмета;
* фон у всех иконок один — `#28323A` с мягкой подсветкой за предметом и тенью под ним,
  предмет занимает ~79 % кадра.

Правила продублированы машинно в `data/trinkets.json` → блок `style` (там же дата
последнего прохода по стилю).

## Описания и сверка картинок

Единый источник данных — **`data/trinkets.json`**. Описания официальные:

* английский — таблица Trinkets (d100), *Player's Handbook*, Wizards of the Coast;
* русский — *«Книга игрока»*, официальный перевод Hobby Games, стр. 159 (безделушки к100).

У каждого предмета в JSON есть блок `icon_check`:

| статус | значение |
|---|---|
| `ok` | картинка соответствует описанию |
| `fixed` | картинка поправлена по описанию (убраны лишние детали) |
| `todo` | требует сверки |

Пример правки: у сферы с дымом (17) была витая латунная подставка, у латунной сферы (23) —
подвесное кольцо, у кристалла (02) — каменное основание. В описаниях ничего этого нет,
поэтому иконки перерисованы: только предмет и ничего лишнего.

## Как добавить предмет

1. Дописать предмет в `data/trinkets.json` (обязательно `icon_check` + официальные ru/en).
2. Сгенерировать исходник 1024×1024 в `masters/painted/<id>-<slug>.png`
   (фон — плоский `RGB 40,50,58`, предмет по центру ~70 % кадра, только то, что есть
   в описании: это и есть «логика соответствия»).
3. Собрать всё одной командой:

```bash
pip install pillow numpy scipy     # зависимости
python3 scripts/build_icons.py
```

Скрипт обновит иконки (обычную и прозрачную), `metadata.csv`, `manifest.json`,
превью и `index.html`. Что он делает с картинкой: определяет цвет плоского фона по
рамке изображения, вырезает предмет по порогу цвета (берётся только самый крупный
связный компонент, поэтому мягкая тень под предметом в маску не попадает),
масштабирует предмет до ~200 px по длинной стороне, центрирует на холсте 256×256
и сглаживает край маски. Порог и сглаживание можно переопределить для отдельного
предмета полями `thr`/`feather`.

## Ориентир по оформлению

Подача сделана по образцу наборов иконок [A-ravlik](https://www.artstation.com/marketplace/p/03oM3/rpg-potion-icons)
(RPG Loot / Potion / Skills Icons). Что скопировано из его превью:

* **`preview/pack-sheet.png`** — страница пака: крупный заголовок «D&D TRINKETS — RPG ICONS»,
  строкой под ним «11 icons · d100 (PHB) · 256x256 pixels size», затем демо-ряд из трёх
  крупных иконок (как у него 2×2 или ряд поверх сетки) и плотная сетка всех иконок
  со скруглёнными плитками, ниже — индекс «номер + название»;
* **`preview/spec-sheet.png`** — технический лист с подписями, статусами сверки и источниками;
* те же принципы, что у него в описании паков: `256x256`, transparent PNG,
  «transparent + backup», тёплые плитки на тёмном фоне.
